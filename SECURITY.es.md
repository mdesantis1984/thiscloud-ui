# Política de seguridad

[English](SECURITY.md) · [Documentación](docs/README.md)

Los reportes de seguridad de Thiscloud UI Aurora deben utilizar los informes privados de vulnerabilidades de GitHub. No publiques vulnerabilidades, credenciales, datos personales ni ejemplos funcionales de explotación en issues o pull requests públicos.

## Versiones con soporte

| Versión | Con soporte |
| --- | --- |
| `0.1.0-rc.5` | Sí |
| `0.1.0-rc.4` | Sí |
| `0.1.0-rc.2` | Sí |
| `0.1.0-rc.1` | Sí |
| Versiones preliminares anteriores | No |

Estas entradas de soporte no indican qué versiones se distribuyen públicamente. El paquete `@thiscloud/ui-web` de este repositorio es privado en `0.1.0-rc.5`; la descarga pública documentada es `0.1.0-rc.1`.

El catálogo en `ui.thiscloud.com.ar` distribuye documentación estática y artefactos de paquetes versionados. No procesa credenciales de productos ni datos de aplicaciones.

## Cómo reportar una vulnerabilidad

Abre la pestaña `Security` del repositorio y selecciona `Report a vulnerability`. Incluye la versión afectada, el impacto, una reproducción mínima y un medio de contacto seguro. Si los informes privados no están disponibles, no publiques los detalles del reporte en issues ni pull requests públicos. Esta política no identifica otro canal privado de contacto.

## Tratamiento

La persona responsable del mantenimiento confirmará la recepción del reporte, validará su impacto, coordinará la solución y publicará un aviso de seguridad cuando corresponda. Los secretos comprometidos se revocan y se eliminan del historial; borrar únicamente el código fuente no se considera una solución.
