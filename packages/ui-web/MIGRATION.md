# Migration

There is no prior public package release to migrate from. For RC1, install the local tarball, import the supported API from `@thiscloud/ui-web`, and validate the consumer's browser or hybrid WebView.

Future public changes follow SemVer: incompatible API changes require a major version after 1.0. Before 1.0, breaking RC changes are documented here. Deprecated public APIs receive a documented replacement and removal version when one exists.
